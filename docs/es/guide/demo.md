# Personalizar WujieDemo

## Inicio rápido {#inicio-rapido}

:::tip
Con el andamiaje de wujie puedes generar un demo con los frameworks de aplicación principal y subaplicación que necesites, además de otras características.
:::

### Instalar wujie-skill {#instalar-wujie-skill}

```js
npx skills add wujie-micro/wujie-skill
```

### Gestores de paquetes soportados {#gestores-de-paquetes}

WujieDemo se gestiona con TurboRepo y soporta varios gestores de paquetes:

- npm
- pnpm
- yarn

### Modos de router {#modos-de-router}

Puedes elegir modos de router distintos (`hash | history`) para la aplicación principal y para las subaplicaciones.
